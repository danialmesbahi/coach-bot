  Messages are included alongside audit actions, with consistent action/actor/time/target

  matching the existing team-audit visibility rule. Private content is never returned.
- Activity pagination/filtering uses a log-only query, not all financial KPI queries.

- Product dialogs dismiss on an outside click (not during upload/save). Reordering has
  a visible toggle, numbered positions, drag target and automatic-save feedback;
  arrow controls remain available for touch and keyboard.
- Analytics labels/explanations are simplified. Client-card type/spacing is polished
  without changing the two-to-five-column responsive grid. Removed the empty sidebar divider.
